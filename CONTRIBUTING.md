# Contributing

Original software contributions are submitted under Apache-2.0. Preserve third-party
notices and do not add reserved artwork to the software license. Use a Signed-off-by
line to certify that you may submit your contribution.

Use disposable files for tests. Changes to source exclusion, restore confirmation,
hashing, verification, error handling or boot signatures require corresponding tests.
Networking and remote storage are outside the official community build.
